# SAS CLI and differential-validator work

This branch groups DeSaint007's four assigned issues in Soroban-Eas/soroban-sas.

## #557 Schema creation

Use `soroban-sas schema create --interactive --registry-contract-id C...`.
The wizard validates individual fields, asks for resolver and revocability,
previews the schema UID from the same Rust canonical hashing helper used in
registration, then prompts before signing. `--export schema.json` writes
the fields and UID without submitting a transaction (no signing key needed).
`schema register` remains available for scripted non-interactive use.

## #560 Deploy all

`soroban-sas deploy-all --network testnet --env-file .env` launches the
maintained repository deployment shell script. `--dry-run` prints a plan and
never sends transactions; mainnet requires explicit `--confirm-mainnet`.
The script builds and binds registry/core/indexer, exports their IDs, and the
JSON response now contains SHA256 hashes of deployed WASM binaries.
Public-network deployments were NOT executed.

## #561 Watch

`soroban-sas watch --contract-id C... --network testnet` polls getEvents
and decodes events using the SDK's authoritative XDR decoder. Use
`--event issued|revoked|schema`, `--schema UID`, `--recipient G...`
and `--poll-seconds 5` to filter. Watches use bounded RPC timeouts, have
no persistent threads, and stop with Ctrl-C. A revocation contains only a UID,
so filtering revocations by schema/recipient requires a separate historical
lookup: currently such filtering fails closed instead of displaying mismatches.
A live RPC end-to-end test remains necessary.

## #570 Differential schema fuzzing

`fuzz/fuzz_targets/differential_schema_fuzz.rs` compares the on-chain Rust
validator with the off-chain JavaScript syntax implementation hosted in a
persistent Node process; input is raw bytes, allowing invalid UTF8 and
invisible/control characters. The target compares valid/invalid/empty
categories and prints the offending base64 on mismatch.
Run:
```sh
cargo fuzz run differential_schema_fuzz fuzz/corpus/differential_schema_fuzz -- -runs=1000000 -max_len=1024
```
or minimize crashes with `scripts/triage-differential-schema.sh
fuzz/artifacts/differential_schema_fuzz/CRASHFILE`.

A local noncoverage-instrumented binary completed 1,000,000 iterations without
mismatch. This is NOT proof of total behavioral equivalence: libFuzzer reported
no coverage feedback under that build. The CI smoke job uses proper cargo-fuzz
instrumentation. Further directed cross-language vectors and full campaign
runs should precede any claim of complete coverage.

# Security Policy

## Supported Versions

Currently, the project is in active development and has not reached a stable release. Security updates will be applied to the `main` branch. 

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** create a public GitHub issue or pull request. Instead, report it privately through one of:

- GitHub's [private security advisory form](../../security/advisories/new) for this repository — this keeps the report and any discussion private until a fix ships, and is the preferred channel since it does not require sharing a maintainer email address that may go stale.

Please include a description of the vulnerability, steps to reproduce it, and its potential impact. We will acknowledge your report and work with you on disclosure timing once a fix is available.

Please see the comprehensive [Security Assumptions and Threat Model](docs/security.md) for a detailed breakdown of the project's trust model, admin capabilities, resolver sandboxing, token custody, and known limitations.
